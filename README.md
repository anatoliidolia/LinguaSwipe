## Можливості

- **Свайп-картки** — англійське слово на лицьовому боці, переклад на звороті. Свайп, кнопки або клавіатура (`←`/`A` — не знаю, `→`/`D` — знаю, `Пробіл` — перевернути).
- **Інтервальні повторення (SRS)** — 6 рівнів Лейтнера: кожне «Знаю» піднімає слово на рівень вище, «Не знаю» повертає на рівень 0 і показує його знову в цій же сесії.
- **Акаунти** — реєстрація та вхід за email і паролем. У кожного користувача своя колекція і свій прогрес, які синхронізуються між пристроями.
- **Додавання слів** — по одному, вставкою списку або імпортом файлу CSV/TXT. Дублікати пропускаються.
- **Мобільний додаток (PWA)** — встановлюється на головний екран Android та iPhone, відкривається на весь екран і запускається без інтернету.

## Як встановити на телефон

| Платформа | Як |
|---|---|
| Android (Chrome) | Відкрити сайт → кнопка **«Встановити»** у банері або «⋮» → «Додати на головний екран» |
| iPhone (Safari) | Відкрити сайт у **Safari** → «Поділитися» → **«На початковий екран»** |

## Формат файлу для імпорту

Кожен рядок — слово і переклад. Підтримуються роздільники `,` `;` табуляція або ` - `. Рядок-заголовок пропускається автоматично.

```csv
word,translation
Deceived,"Ошуканий, обдурений"
Temptation,Спокуса
Endure - Витримувати, терпіти
```

## Як це влаштовано

```
Браузер / телефон (index.html, PWA)
   │  supabase-js
   ▼
Supabase
   ├─ Auth      → акаунти, вхід за email і паролем
   └─ Postgres  → таблиця words, захищена Row Level Security
```

- **Фронтенд** — один файл `index.html`: Vue 3, Tailwind CSS, Font Awesome (з CDN). Збірка не потрібна.
- **Бекенд** — [Supabase](https://supabase.com) (безкоштовний тариф). Власного сервера немає.
- **Безпека** — у сайті використовується лише публічний `anon`-ключ. Доступ до даних обмежують правила RLS у базі: кожен користувач читає і змінює тільки свої слова (`auth.uid() = user_id`).
- **Хостинг** — GitHub Pages, публікація через GitHub Actions.

### Структура

| Файл | Призначення |
|---|---|
| `index.html` | Увесь застосунок: інтерфейс, логіка, робота з Supabase |
| `manifest.json`, `sw.js`, `icons/` | PWA: встановлення на телефон і офлайн-запуск |
| `supabase_setup.sql` | Створення таблиці `words` і правил доступу в Supabase |
| `.github/workflows/pages.yml` | Публікація на GitHub Pages з підстановкою налаштувань Supabase |

## Розгортання власної копії

1. **Supabase.** Створіть безкоштовний проєкт на [supabase.com](https://supabase.com).
   - **SQL Editor** → виконайте вміст `supabase_setup.sql`.
   - **Authentication → Sign In / Providers → Email** → вимкніть «Confirm email» (безкоштовний тариф надсилає лише кілька листів на годину).
   - **Project Settings → API Keys** → скопіюйте Project URL і `anon` / `publishable` ключ. Ключ `service_role` / `secret` у сайт **не додавайте**.
2. **GitHub.** Зробіть fork репозиторію і в ньому:
   - **Settings → Secrets and variables → Actions → Variables** → додайте `SUPABASE_URL` і `SUPABASE_KEY`.
   - **Settings → Pages → Source** → **GitHub Actions**.
3. Зробіть push у `main` — workflow підставить налаштування в `index.html` і опублікує сайт.

### Локальний запуск

Service worker і вхід працюють лише через `http://localhost` або `https`, тож файл треба віддавати через сервер. Спершу підставте свої значення замість `__SUPABASE_URL__` і `__SUPABASE_KEY__` в `index.html` (не комітьте ці зміни), потім:

```bash
python3 -m http.server 8000
# або
php -S localhost:8000
```

і відкрийте http://localhost:8000.
