## Можливості

- **Свайп-картки** — англійське слово (і транскрипція, якщо є) на лицьовому боці, переклад на звороті. Свайп, кнопки або клавіатура (`←`/`A` — не знаю, `→`/`D` — знаю, `Пробіл` — перевернути).
- **Інтервальні повторення (SRS)** — 6 рівнів Лейтнера: кожне «Знаю» піднімає слово на рівень вище, «Не знаю» повертає на рівень 0 і показує його знову в цій же сесії.
- **Акаунти** — реєстрація та вхід за email і паролем. У кожного користувача своя колекція і свій прогрес, які синхронізуються між пристроями.
- **Загальний словник** — перемикач «Мої слова / Усі слова»: можна тренуватися на словах усіх користувачів (без дублікатів) з окремим прогресом. Чужі слова лише для перегляду.
- **Гостьовий режим** — без реєстрації: гість бачить загальний словник, а його прогрес зберігається в браузері.
- **Додавання слів** — по одному, вставкою списку або імпортом файлу CSV/TXT. Транскрипція — необов'язкове поле. Дублікати пропускаються.
- **Розширення для Chrome** — виділіть слово на будь-якій сторінці, введіть переклад (і за бажанням транскрипцію) і натисніть «Надіслати»: слово потрапить у вашу колекцію (а отже й у загальний словник для гостей).
- **Мобільний додаток (PWA)** — встановлюється на головний екран Android та iPhone, відкривається на весь екран і запускається без інтернету.

## Як встановити на телефон

| Платформа | Як |
|---|---|
| Android (Chrome) | Відкрити сайт → кнопка **«Встановити»** у банері або «⋮» → «Додати на головний екран» |
| iPhone (Safari) | Відкрити сайт у **Safari** → «Поділитися» → **«На початковий екран»** |

## Розширення для Chrome

1. Скопіюйте `chrome-extension/config.example.js` у `chrome-extension/config.js` і підставте Project URL та `anon`-ключ Supabase (ті самі, що й для сайту). `config.js` не комітиться.
2. Chrome → `chrome://extensions` → увімкніть **«Режим розробника»** → **«Завантажити розпаковане»** → оберіть папку `chrome-extension`.
3. Натисніть іконку LinguaSwipe на панелі браузера і увійдіть тим самим email і паролем, що й у додатку. Сесія зберігається і оновлюється автоматично.
4. Виділіть англійське слово (подвійний клік) — під ним з’явиться поле з підказкою перекладу: з вашого словника, із загального словника або автопереклад. Транскрипцію можна ввести в окреме необов'язкове поле (її теж підставлено, якщо слово вже є у словнику). Виправте за потреби і натисніть **«Надіслати»** (або `Enter`). `Esc` — закрити.

Також можна: правий клік по виділеному → «Додати у LinguaSwipe», або додати слово вручну у вікні розширення. Автопоказ поля при виділенні вимикається там само. Якщо слово вже є у колекції, переклад буде оновлено, а не продубльовано.

Нові слова потрапляють у таблицю `words` користувача, тож автоматично з’являються і в загальному словнику, який бачать гості (`public_words()`). Змін у базі розширення не потребує.

## Формат файлу для імпорту

Кожен рядок — слово, необов'язкова транскрипція у квадратних дужках і переклад. Підтримуються роздільники `,` `;` табуляція або ` - `. Порожні дужки `[]` або відсутня колонка — слово без транскрипції. Рядок-заголовок пропускається автоматично.

```csv
word,transcription,translation
Deceived,[dɪˈsiːvd],"Ошуканий, обдурений"
Temptation,[],Спокуса
Reluctant,Неохочий
Endure - [ɪnˈdjʊə] - Витримувати, терпіти
```

## Як це влаштовано

```
Браузер / телефон (index.html, PWA)
   │  supabase-js
   ▼
Supabase
   ├─ Auth      → акаунти, вхід за email і паролем
   └─ Postgres  → таблиця words, захищена Row Level Security
```

- **Фронтенд** — один файл `index.html`: Vue 3, Tailwind CSS, Font Awesome (з CDN). Збірка не потрібна.
- **Бекенд** — [Supabase](https://supabase.com) (безкоштовний тариф). Власного сервера немає.
- **Безпека** — у сайті використовується лише публічний `anon`-ключ. Доступ до даних обмежують правила RLS у базі: кожен користувач читає і змінює тільки свої слова (`auth.uid() = user_id`).
- **Хостинг** — GitHub Pages, публікація через GitHub Actions.

### Структура

| Файл | Призначення |
|---|---|
| `index.html` | Увесь застосунок: інтерфейс, логіка, робота з Supabase |
| `manifest.json`, `sw.js`, `icons/` | PWA: встановлення на телефон і офлайн-запуск |
| `chrome-extension/` | Розширення для Chrome: додавання виділених слів (Manifest V3, без збірки) |
| `supabase_setup.sql` | Створення таблиці `words` і правил доступу в Supabase |
| `.github/workflows/pages.yml` | Публікація на GitHub Pages з підстановкою налаштувань Supabase |

## Розгортання власної копії

1. **Supabase.** Створіть безкоштовний проєкт на [supabase.com](https://supabase.com).
   - **SQL Editor** → виконайте вміст `supabase_setup.sql`.
   - **Authentication → Sign In / Providers → Email** → вимкніть «Confirm email» (безкоштовний тариф надсилає лише кілька листів на годину).
   - **Project Settings → API Keys** → скопіюйте Project URL і `anon` / `publishable` ключ. Ключ `service_role` / `secret` у сайт **не додавайте**.
2. **GitHub.** Зробіть fork репозиторію і в ньому:
   - **Settings → Secrets and variables → Actions → Variables** → додайте `SUPABASE_URL` і `SUPABASE_KEY`.
   - **Settings → Pages → Source** → **GitHub Actions**.
3. Зробіть push у `main` — workflow підставить налаштування в `index.html` і опублікує сайт.

### Локальний запуск

Service worker і вхід працюють лише через `http://localhost` або `https`, тож файл треба віддавати через сервер. Спершу підставте свої значення замість `__SUPABASE_URL__` і `__SUPABASE_KEY__` в `index.html` (не комітьте ці зміни), потім:

```bash
python3 -m http.server 8000
# або
php -S localhost:8000
```

і відкрийте http://localhost:8000.
