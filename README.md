## Можливості

- **Свайп-картки** — англійське слово (і транскрипція, якщо є) на лицьовому боці, переклад на звороті. Свайп, кнопки або клавіатура (`←`/`A` — не знаю, `→`/`D` — знаю, `Пробіл` — перевернути).
- **Інтервальні повторення (SRS)** — 6 рівнів Лейтнера: кожне «Знаю» піднімає слово на рівень вище і відкладає його на 1, 3, 7, 16, 30 днів (вивчені — на 60), з невеликим розкидом. У тренування потрапляють лише слова, яким настав час; «Не знаю» повертає слово на рівень 0 і показує його знову в цій же сесії. Можна «повторити наперед» без впливу на розклад, а статистика показує прогноз повторень на сьогодні, завтра і тиждень.
- **Акаунти** — реєстрація та вхід за email і паролем. У кожного користувача своя колекція і свій прогрес, які синхронізуються між пристроями.
- **Загальний словник** — перемикач «Мої слова / Усі слова»: можна тренуватися на словах усіх користувачів (без дублікатів) з окремим прогресом. Чужі слова лише для перегляду.
- **Супер-адмін** — може видаляти слова (наприклад, нецензурні) із загального словника в усіх користувачів одразу.
- **Гостьовий режим** — без реєстрації: гість бачить загальний словник, а його прогрес зберігається в браузері.
- **Додавання слів** — по одному, вставкою списку або імпортом файлу CSV/TXT. Транскрипція — необов'язкове поле. Дублікати пропускаються.
- **Розширення для Chrome** — виділіть слово на будь-якій сторінці, введіть переклад (і за бажанням транскрипцію) і натисніть «Надіслати»: слово потрапить у вашу колекцію (а отже й у загальний словник для гостей).
- **Мобільний додаток (PWA)** — встановлюється на головний екран Android та iPhone, відкривається на весь екран і запускається без інтернету.

## Як встановити на телефон

| Платформа | Як |
|---|---|
| Android (Chrome) | Відкрити сайт → кнопка **«Встановити»** у банері або «⋮» → «Додати на головний екран» |
| iPhone (Safari) | Відкрити сайт у **Safari** → «Поділитися» → **«На початковий екран»** |

## Розширення для Chrome

1. Скопіюйте `chrome-extension/config.example.js` у `chrome-extension/config.js` і підставте Project URL та `anon`-ключ Supabase (ті самі, що й для сайту). `config.js` не комітиться.
2. Chrome → `chrome://extensions` → увімкніть **«Режим розробника»** → **«Завантажити розпаковане»** → оберіть папку `chrome-extension`.
3. Натисніть іконку LinguaSwipe на панелі браузера і увійдіть тим самим email і паролем, що й у додатку. Сесія зберігається і оновлюється автоматично.
4. Виділіть англійське слово (подвійний клік) — під ним з’явиться поле з підказкою перекладу: з вашого словника, із загального словника або автопереклад. Транскрипцію можна ввести в окреме необов'язкове поле (її теж підставлено, якщо слово вже є у словнику). Виправте за потреби і натисніть **«Надіслати»** (або `Enter`). `Esc` — закрити.

Також можна: правий клік по виділеному → «Додати у LinguaSwipe», або додати слово вручну у вікні розширення. Автопоказ поля при виділенні вимикається там само. Якщо слово вже є у колекції, переклад буде оновлено, а не продубльовано.

Нові слова потрапляють у таблицю `words` користувача, тож автоматично з’являються і в загальному словнику, який бачать гості (`public_words()`). Змін у базі розширення не потребує.

## Формат файлу для імпорту

Кожен рядок — слово, необов'язкова транскрипція у квадратних дужках і переклад. Підтримуються роздільники `,` `;` табуляція або ` - `. Порожні дужки `[]` або відсутня колонка — слово без транскрипції. Рядок-заголовок пропускається автоматично.

```csv
word,transcription,translation
Deceived,[dɪˈsiːvd],"Ошуканий, обдурений"
Temptation,[],Спокуса
Reluctant,Неохочий
Endure - [ɪnˈdjʊə] - Витримувати, терпіти
```

## Міграції бази даних

Користувацькі дані вже є, тож схему не перестворюють: кожна зміна — окремий файл у `migrations/`, який лише додає (колонки, функції, правила) і нічого не видаляє. Нову міграцію виконайте в Supabase → **SQL Editor** перед публікацією сайту, що її використовує. Усі міграції можна безпечно запускати повторно.
## Ролі: адмін, викладач, студент

| Роль | Що може |
|---|---|
| **Студент** (усі за замовчуванням) | Лише свій словник |
| **Викладач** | Свій словник + словники своїх студентів: додавати, змінювати, видаляти слова. Бачить список користувачів і позначає, хто його студент |
| **Адмін** | Усе: словник будь-якого користувача, призначення викладачів, видалення слів із загального словника |

Викладачі й адміни бачать вкладку **«Студенти» / «Користувачі»** (іконка 👥): пошук за email, фільтр «Мої студенти», кнопки «Додати в студенти», «Зробити викладачем» (лише адмін) і «Словник».

Призначити викладача: адмін → «Користувачі» → **«Зробити викладачем»**, або в SQL Editor:

```sql
insert into public.teachers (user_id)
select id from auth.users where email = 'teacher@example.com'
on conflict do nothing;
```

Права перевіряє база, а не інтерфейс: правила RLS таблиці `words` не змінювались, а чужі словники змінюються лише через функції `student_*()`, які перевіряють `can_manage_user()`. Якщо викладача позбавити ролі, доступ до його студентів зникає одразу. Розширення Chrome працює як раніше: воно додає слова лише у власний словник.

## Супер-адмін

Адмін бачить у шапці позначку **«Адмін»**, а в режимі **«Усі слова» → Словник** біля кожного слова кнопку видалення. Вона прибирає слово в усіх користувачів разом із прогресом.

Призначити адміна (користувач має бути вже зареєстрований) — у Supabase → SQL Editor:

```sql
insert into public.admins (user_id)
select id from auth.users where email = 'you@example.com'
on conflict do nothing;
```

Забрати права: `delete from public.admins where user_id = (select id from auth.users where email = 'you@example.com');`

Список адмінів змінюється лише через SQL Editor: сайт і розширення не мають доступу до таблиці `admins`, а видалення чужих слів перевіряється в базі (`is_admin()`), а не лише в інтерфейсі.

## Як це влаштовано

```
Браузер / телефон (Vue-додаток, PWA)
   │  supabase-js
   ▼
Supabase
   ├─ Auth      → акаунти, вхід за email і паролем
   └─ Postgres  → таблиця words, захищена Row Level Security
```

- **Фронтенд** — Vue 3 + Pinia, збірка Vite, Tailwind CSS, Font Awesome (з CDN).
- **Бекенд** — [Supabase](https://supabase.com) (безкоштовний тариф). Власного сервера немає.
- **Безпека** — у сайті використовується лише публічний `anon`-ключ. Доступ до даних обмежують правила RLS у базі: кожен користувач читає і змінює тільки свої слова (`auth.uid() = user_id`).
- **Хостинг** — GitHub Pages, публікація через GitHub Actions.

### Структура

| Файл | Призначення |
|---|---|
| `index.html`, `src/main.js`, `src/App.vue` | Точка входу і каркас додатку |
| `src/views/` | Вкладки: тренування, словник, прогрес SRS |
| `src/components/` | Шапка, екран входу, картка зі свайпом, модальні вікна |
| `src/stores/` | Стан (Pinia): `auth`, `words`, `practice`, `ui` |
| `src/lib/` | Логіка без інтерфейсу: Supabase, перевірка символів, розбір CSV, localStorage |
| `public/` (`manifest.json`, `sw.js`, `icons/`) | PWA: встановлення на телефон і офлайн-запуск |
| `vite.config.js` | Збірка; підставляє у `sw.js` список файлів і версію кешу |
| `chrome-extension/` | Розширення для Chrome: додавання виділених слів (Manifest V3, без збірки) |
| `supabase_setup.sql` | Початкова схема: таблиця `words` і правила доступу в Supabase |
| `migrations/` | Зміни схеми після запуску — виконуються по черзі, дані не видаляють |
| `.github/workflows/pages.yml` | Збірка (`npm run build`) і публікація `dist/` на GitHub Pages |
| `CLAUDE.md` | Правила для AI-асистента: git, міграції, екранування |

## Розгортання власної копії

1. **Supabase.** Створіть безкоштовний проєкт на [supabase.com](https://supabase.com).
   - **SQL Editor** → виконайте вміст `supabase_setup.sql`, потім по черзі всі файли з `migrations/` (`001_…`, `002_…`, …).
   - **Authentication → Sign In / Providers → Email** → вимкніть «Confirm email» (безкоштовний тариф надсилає лише кілька листів на годину).
   - **Project Settings → API Keys** → скопіюйте Project URL і `anon` / `publishable` ключ. Ключ `service_role` / `secret` у сайт **не додавайте**.
2. **GitHub.** Зробіть fork репозиторію і в ньому:
   - **Settings → Secrets and variables → Actions → Variables** → додайте `SUPABASE_URL` і `SUPABASE_KEY`.
   - **Settings → Pages → Source** → **GitHub Actions**.
3. Зробіть push у `main` — workflow збере додаток з вашими налаштуваннями і опублікує сайт.

### Локальний запуск

Потрібен Node.js 20+.

```bash
cp .env.example .env.local   # підставте Project URL і anon-ключ Supabase
npm install
npm run dev                  # http://localhost:5173
```

Перевірити продакшен-збірку (разом із service worker): `npm run build && npm run preview`.
