# Changelog

Усі помітні зміни LinguaSwipe. Нові записи — зверху, згруповані за датою.
Розділи: **Додано**, **Змінено**, **Виправлено**, **База даних** (міграції, які треба виконати в Supabase → SQL Editor **до** деплою).

## 2026-10-24

### Додано
- **Зворотний напрямок тренування `UA → EN`**: на картці переклад, треба згадати англійське слово, на звороті — слово з транскрипцією. Перемикач над карткою: `EN → UA` / `UA → EN` / `Обидва`, вибір запам'ятовується.
  - У кожного напрямку свій рівень і розклад повторень.
  - Після основної сесії — кнопка «Тепер навпаки: UA → EN (N)».
  - Статистика з перемикачем напрямку.
- **Інтервальні повторення**: «Знаю» відкладає слово на 1, 3, 7, 16, 30 днів залежно від рівня (вивчені — на 60), з розкидом ±10%. У тренування потрапляють лише слова, яким настав час.
  - Підказка під кнопкою «Знаю»: коли слово повернеться («+3 дні»).
  - Екран «На сьогодні все повторено» з датою наступного повторення.
  - «Повторити наперед» — тренування без впливу на розклад.
  - Прогноз у статистиці (сьогодні / завтра / 7 днів) і «повтор завтра» біля слів у словнику.
- **Ролі викладача і студента**:
  - Викладач позначає своїх студентів і редагує їхні словники: додає (по одному, текстом, файлом), змінює і видаляє слова.
  - Адмін може все: словник будь-якого користувача, призначення викладачів.
  - Вкладка «Студенти» / «Користувачі»: пошук за email, фільтр «Мої студенти», кнопки ролей.
  - Права перевіряє база (`can_manage_user`), правила RLS таблиці `words` не змінювались.
- `CLAUDE.md` — правила для AI-асистента: git, міграції, екранування, сумісність.

### Змінено
- **Архітектура фронтенду**: один `index.html` розбито на Vue-додаток (Vite + Pinia) — `src/views`, `src/components`, `src/stores`, `src/lib`.
  - Залежності з npm замість CDN, Tailwind збирається разом із додатком.
  - Деплой на GitHub Pages: `npm run build` → `dist/`, налаштування Supabase передаються як змінні збірки.
  - Service worker отримує список зібраних файлів і нову версію кешу з кожною збіркою.
- Спільна логіка підготовки слів (`src/lib/wordEditing.js`) і компонент списку слів (`WordList.vue`) для власного словника і словника студента.

### Виправлено
- Власні слова завантажуються сторінками: колекції понад 1000 слів більше не обрізаються.
- Плагін service worker у `vite.config.js` більше не підміняє справжню помилку збірки своєю (`ENOENT … sw.js`).
